# Ordella — Web Project First Deliverable

This is a static frontend prototype built with HTML and Bootstrap 5.3.3. It does not use a separate CSS file or custom stylesheet.

## Pages
- `index.html` — main landing page
- `login.html` — login page with seller/customer role selection
- `signup.html` — registration page with seller/customer role selection
- `seller-home.html` — seller dashboard homepage
- `customer-home.html` — customer homepage

## Run
Open `index.html` in a browser. Bootstrap CSS and JavaScript are loaded from jsDelivr CDN, so an internet connection is required.

## Scope
This is a static prototype. Login, signup, search, product actions, and order information are demonstrations only. No authentication, database, backend, or ASP.NET Core MVC functionality is included in this first deliverable.
